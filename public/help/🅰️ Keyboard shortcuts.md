# 🅰️ Keyboard shortcuts

## Create
- `Space` — new card at the pointer
- `Tab` — add a child
- `Enter` — add a sibling
- `D` — duplicate
- `Delete` — remove

## Select
- `⌘/Ctrl A` — select every card on the canvas (inside an open frame: just its contents)
- `⌘/Ctrl` + click — add a card to the selection
- drag on empty canvas — rubber-band select

## Clipboard
- `⌘/Ctrl C` — copy card + subtree
- `⌘/Ctrl X` — cut
- `⌘/Ctrl V` — paste (as child of the selected card, else at the pointer)
- `⌥/Alt` + drag a card — save it as a `.md` file (drop on your file manager)

## Edit
- `F2` — rename
- `E` — edit note
- `X` — collapse / expand

## Move around
- `↑` — open the selected frame
- `↓` — leave the frame you're in
- `→` — unfold the branch
- `←` — fold it away

## View
- `F` — fit / focus
- `/` — find
- `O` — outline view
- `R` — read-only
- `S` — sketch

## History
- `⌘/Ctrl Z` — undo
- `⌘/Ctrl ⇧ Z` — redo

## Help
- `F1` — open this help
